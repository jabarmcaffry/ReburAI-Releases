Before you start

This preview runs on your computer. AI tasks currently require an OpenAI API key in Rebur’s Local setup. API usage is billed by OpenAI. Managed Rebur accounts and subscriptions are not connected yet.

Preview builds

These builds are unsigned and macOS is not notarized. Your operating system may warn or block installation. Linux key storage requires an unlocked system keyring. Keep your system’s security checks enabled.
